## What's new in RDM Eq 1.1.0

- **In-app updates**: RDM Eq now checks GitHub for new versions (Settings → Updates, or About → Check for Updates). Downloads show progress, can resume after a dropped connection, and are verified (SHA-256 checksum and signing certificate) before Android's installer asks you to confirm. Your presets and settings are kept.
- **New About screen** with developer credit, installed version, build number and update status.
- Automatic update check when the app opens (at most every 12 hours; can be turned off). Optional beta updates.
- The app now has internet permission, used **only** to read GitHub Releases. The equalizer still works fully offline.

**Upgrading from 1.0.0:** 1.0.0 has no updater, so install this APK once by hand (it installs over 1.0.0 and keeps your presets). From 1.1.0 on, updates arrive inside the app.
