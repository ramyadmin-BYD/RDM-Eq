## RDM Eq 1.1.1

- If the head unit's security check (for example Google Play Protect) or the firmware blocks an in-app update, RDM Eq now explains what happened and links to the release page for a manual install, instead of silently returning to the Install button.
- Release notes in the update dialog no longer repeat the "What's new" heading.
- Checking for updates now re-verifies a previously downloaded file against the latest release information.
- Includes everything from 1.1.0 (in-app updates, new About screen).

**Coming from 1.0.0?** Install this APK once by hand; it installs over 1.0.0 and keeps your presets. Later versions arrive inside the app.
